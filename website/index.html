See which pages people actually read on your site.

Not another Umami Docker deploy — a small FastAPI app you can fork. Embed one script, store events in Postgres, open a password-protected dashboard. Built for developers who want analytics without giving up control.

Three steps. No SDK required.

Install the Railway template, paste one line of HTML, open your dashboard when you are curious.

  1. Deploy the template

    Railway provisions the app and PostgreSQL. Set a dashboard password and you are done with infrastructure.

  2. Add the script

    <script src="https://your-app.up.railway.app/script.js" defer></script>

  3. Check the dashboard

    Visit /dashboard?key=YOUR_PASSWORD for top pages and referrers from the past week.

Built for people who ship small things

If you run a personal site, a weekend SaaS, or a client landing page, you probably do not need enterprise analytics on day one. You need to know whether anyone found your docs and which blog post got traction.

  • Portfolio and personal sites
  • Indie side projects before Product Hunt
  • Internal tools with a public marketing page
  • MVPs where Google Analytics feels like overkill

Honest limits

No funnels, session replay, or ad attribution. If you outgrow it, export from Postgres or move to Umami.

Why deploy this instead of Umami #47?

Umami dominates Railway Analytics. This template is for developers who want to read the source, change the schema, and ship analytics without maintaining a Docker fork.
